### Mechanics

You can move and shoot and stuff and die.

### Controls

- Rotate ship: AD / Left and Right
- Thrust: W / UP
- Shoot: Space Bar / Z / LMB

### Goals

- [x] Player space ship. It should be able to rotate and thrust. Thrust will accelerate the ship in the direction it is facing. No friction.
- [x] Player can shoot. The ship will shoot in the direction its facing and destroy asteroids. Bullets will despawn after a while.
- [x] Asteroids with 3 different sizes.
  - [x] Asteroids will break into 2 smaller asteroids when shot. The smallest variation will disappear when shot.
  - [X] Asteroids will drift around until the hit the player or are shot. If the player collides with one, they lose a life. Player explodes, after 3 seconds respawn in the middle.
  - [X] Asteroid spawns in waves. For example, 4 big asteroids spawn in moving in random directions - the player kills all - then 5 big asteroids spawn after a short delay.
  - [x] Varying speed
- [x] Add score
- [x] Add screen wrapping.
- [ ] Add menus and UI.
  - [X] Start menu
  - [X] Gameover
  - [ ] Credits
- [ ] Add sound effects and particles effects.
  - [ ] Shoot
  - [ ] Player hit
  - [ ] Asteroid hit
  - [ ] Gameover
  - [ ] Life up

### Bonus

- [ ] Add a flying saucer that enters the screen and shoots at the player from time to time. The saucer should generally aim towards the player, but shouldn’t have too good of aim!
- [ ] Add a “hyperspace warp” that moves the player to a random part of the screen. The warp is a last-ditch attempt to dodge an asteroid, but it could place you in a worse predicament!
